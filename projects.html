🤖 AeroEye: Snake-like Robot System for Aircraft Engine Damage Detection

#object detection#robotic perception#deep learning
Project details

AeroEye is a snake-like robot system designed to inspect aircraft engines for damage. Its flexible structure enables access to confined spaces, combining robotic mobility with visual defect detection.

I joined Tongji University’s QiDi program and served as a key team member under the guidance of Prof. Peng Qi. Supported by the China National University Student Innovation & Entrepreneurship Development Program, I was primarily responsible for robotic perception and contributed to system development.

Patents

I am the first student inventor on two invention patent applications, with my advisor listed as the first inventor: a YOLOv5-based method for aircraft engine crack detection, and an obstacle avoidance method and system for an aircraft engine defect detection robot. Both applications are currently undergoing substantive examination.

Gesture Recognition with Infrared Sensors

#embedded systems#sensor-based perception#K-Means
Project details

A gesture recognition system built with an STM32G0 microcontroller and 16 ITR20001/T24 infrared sensors. It recognizes rock, paper, and scissors gestures near the PCB and displays the predicted class using LEDs.

Developed as a course project at Tongji University, the system combines circuit schematic design and PCB layout in KiCad, sensor data collection, 16-dimensional K-Means clustering, and embedded implementation. The repository includes both PC-side inference with LED output and MCU-side inference.

Embedded Handwritten Digit Recognition

#embedded AI#CNN#digit recognition
Project details

A handwritten digit recognition system deployed on the STM32H747I-DISCO development board, bringing a convolutional neural network to an embedded device.

Built for the Embedded Systems course at Tongji University, the project uses a basic CNN for digit classification on MNIST and CubeAI to integrate the neural network with the embedded system. The repository includes Python model development, embedded project code, and demonstrations.
